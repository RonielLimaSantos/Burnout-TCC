# Burning Out

**Um projeto acadêmico de desenvolvimento de jogos digitais.**

# Sobre o projeto

Burning Out é um jogo desenvolvido como parte de um Trabalho de Conclusão de Curso (TCC), com o objetivo de aplicar conhecimentos de programação, design, desenvolvimento de jogos e criação de narrativas interativas.

O jogo acompanha Sandra, uma enfermeira que enfrenta os desafios de uma rotina hospitalar intensa, lidando com atendimentos, emergências e situações que refletem o esgotamento profissional.

A proposta é explorar, por meio dos jogos digitais, os impactos de uma rotina de trabalho desgastante e a importância da saúde emocional dos profissionais.

## Status do desenvolvimento

*O jogo ainda está em desenvolvimento.*

Novas funcionalidades, melhorias, correções de bugs, cenários, personagens e elementos da narrativa estão sendo implementados gradualmente.

Por isso, algumas mecânicas podem estar incompletas ou sofrer alterações durante o processo de desenvolvimento.

 Desenvolvimento

O projeto envolve diferentes áreas do desenvolvimento de jogos:

- Programação e lógica de jogos;
- Criação de personagens e cenários;
- Design de interfaces;
- Desenvolvimento de sistemas interativos;
- Construção de diálogos e narrativas;
- Implementação de mecânicas de gameplay.

  Objetivo do projeto

Desenvolver um jogo digital que demonstre os conhecimentos adquiridos durante a formação acadêmica, unindo criatividade, programação e narrativa para abordar um tema relevante para a sociedade.

  Observações

- Projeto desenvolvido para fins acadêmicos.
- Produzido como Trabalho de Conclusão de Curso (TCC).
- O conteúdo está sujeito a alterações.
- O jogo ainda não representa uma versão final.
